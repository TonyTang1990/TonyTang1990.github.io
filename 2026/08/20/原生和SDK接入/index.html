前言

在游戏开发过程中，无论是做手游还是端游还是小游戏，我们或多或少都会需要接入第三方SDK去支持一些原生功能，不会全部都自己从0开发(比如广告SDK，统计SDK，支付SDK等)，本章节就是为了深入SDK接入实战，打通SDK接入流程，同时深入Unity+原生开发，了解原生开发过程中的理论和实践知识。

原生开发

原生开发是指除了Unity提供的官方功能，我们还能在不同平台自己进行原生功能开发。

Android原生开发

Android我们通过自定义MainActivity和编写原生Android功能代码实现原生功能，然后在Unity测通过AndroidJavaClass去访问原生Android Activty和调用原生代码功能。Untiy支持我们自己导出**AAR(包含代码和资源)或者Jar(仅仅包含代码)**然后放到Plugins/Android/libs目录下直接使用，接下来我将深入从0实战如何搭建一个能够自定义开发原生功能流程框架搭建。

为什么我们的Android Library工程不需要配置像Unity导出的Gradle工程相关的NDK配置？为什么 Unity 导出工程需要 NDK？

Unity 导出的 unityLibrary/build.gradle 不只是普通 Android Library，它包含：

  • Unity Player 运行时；
  • IL2CPP 生成的 C++；
  • Unity 原生库；
  • 游戏程序集和资源；
  • 多个 CPU 架构的 .so；
  • IL2CPP 编译任务。

而我们编译Android Library的工程只有Android Java代码，是构建一个纯Java Android Library的AAR所以不需要使用NDK工具，如果未来需要包含C++或者.so或者使用JNI啥的才需要NDK。

SDK

SDK 是「Software Development Kit」的縮寫，中文稱為「軟體開發工具套件」

很多跨平台功能需要处理原生的东西，且这些功能可以说是对大部分游戏都需求 统一的，所以很多时候这些功能(比如广告SDK，统计SDK，支付SDK等)会被做成SDK供我们直接集成使用。

Firebase

Firebase 是一组面向移动端的云服务和运营工具。它把账号、数据存储、云函数、崩溃收集、数据分析、远程配置、推送等常见能力组合在一起，并提供 Unity/C++ SDK。

Firebase能提供很多我游戏开发中会用到的一些SDK功能，比如崩溃统计，数据大大点，消息推送，登录授权等。

在游戏开发过程中如果我们的游戏走海外移动端，基本都会选Firebase。但在国内受限于网络的原因，部分Firebase功能我们需要选择其他替代品。

Firebase Unity接入

接下来以实战Unity接入Firebase的崩溃监控和数据功能为例。

Firebase接入条件限制：

  • 安装 Unity 2021 LTS 或更高版本。更早的版本也可能兼容，但不享受积极支持。

  • （仅限 Apple 平台）安装以下各项：

    • Xcode 16.2 版或更高版本
    • CocoaPods 1.12.0 或更高版本

  • 确保您的 Unity 项目满足以下要求：

    • 对于 iOS - 目标为 iOS 15 或更高版本
    • 对于 tvOS - 目标为 tvOS 15 或更高版本
    • 对于 Android - 目标 API 级别为 23 (Marshmallow) 或更高版本

  • 设置一台实体设备或使用模拟器运行您的应用。

    • 对于 Apple 平台 - 设置实体设备或使用 iOS 或 tvOS 模拟器。

      您是要用 Cloud Messaging？

    • 对于 Android - 模拟器必须使用包含 Google Play 的模拟器映像。

  • 使用您的 Google 账号登录 Firebase

FirebaseApp.androidlib不是Firebase Analytics SDK本体，它是Firebase项目配置资料库(比如AndroidManifest.xml(定义Firebase的Android Activity)和google-services.xml(定义一些Android资源icon名称))

mainTemplate.gradle 这是Unity Android 构建中的主 Android Library 模块 Gradle 模板，主要用于生成unityLibrary/build.gradle。

settingsTemplate.gradle是根Gradle工程，主要负责配置一些内容去决定哪里寻找插件和依赖、工程包含哪些模块。

gradleTemplate.properties是Unity 生成gradle.properties的模版，它控制整个 Gradle 构建进程的属性。
